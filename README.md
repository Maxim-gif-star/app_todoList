# app_todoList

Десктопное приложение **Noctis**. Референсы (`.kra` и выгрузки) лежат снаружи, в соседней папке `_ref`.

## Запуск

Двойной клик по готовому файлу:

`release/Noctis.exe`

Пока пилим фичи, окно на компьютере без браузера:

```
npm start
```

Собрать `.exe` заново:

```
npm run dist
```
